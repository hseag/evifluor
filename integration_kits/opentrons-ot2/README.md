# Opentrons OT-2 Integration

This directory contains the current eviFluor Duo integration examples for the Opentrons OT-2 liquid handler.

Included content:

- `labware` contains the custom labware definitions used by the integration examples.
- `protocols` contains example OT-2 protocols for the supported workflows.

The user-facing setup and usage guide is documented in [Opentrons OT-2 Liquid Handler Integration](../../doc/liquid-handler-ot2.md).
