# Integration

This directory contains integration examples for different liquid handlers in the context of eviFluor Duo.

It is intended as a place for practical examples, protocols, and related definitions that can serve as a starting point for integrating and operating different systems.

At the moment, only an example for the `Opentrons OT-2` is available:

- [opentrons-ot2](./opentrons-ot2) contains the existing integration kit for the OT-2.
- `labware` contains labware definitions and helper files.
- `protocols` contains example protocols and related scripts.

Additional liquid-handler integration kits can be added to this directory in the future.
