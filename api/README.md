# eviFluor Duo APIs

This directory contains the software interfaces for integrating the eviFluor Duo Fluorometer into customer applications, automation workflows, and service tooling.

## Quick Start

- C interface: [C](./c/)
- C# interface: [C#](./csharp/)
- Python interface: [Python](./python/)

## Which API to Use

- Use `C` if you want a command line based integration for scripting, service tasks, or operational workflows.
- Use `C#` if you are building a .NET application and want either a guided workflow or direct device access.
- Use `Python` if you want the broadest integration surface with high-level API, low-level API, CLI, and REST API.
