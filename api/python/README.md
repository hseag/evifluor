# eviFluor Duo Python Interface

This directory contains the Python interface for the eviFluor Duo Fluorometer.
It is the broadest software entry point and supports direct scripting, application integration, command line usage, and HTTP-based control.

## Quick Start

- Main documentation: [Python Interfaces](../../doc/python.md)
- High-level API: [Python High-Level API](../../doc/python-high-level.md)
- Low-level API: [Python Low-Level API](../../doc/python-low-level.md)
- REST API: [Python REST API](../../doc/python-rest.md)
- CLI: [Python Command Line Interface](../../doc/python-cli.md)
- Typical installation: Python wheel plus `pyserial`

## What You Get

The Python package is suitable if you want to:

- script measurement workflows quickly
- integrate the device into Python applications
- use a CLI for service or automation tasks
- expose the workflow through a REST API

This makes Python a good fit for:

- orchestration and automation
- test systems
- external software integration over HTTP
- rapid prototyping around the eviFluor workflow
