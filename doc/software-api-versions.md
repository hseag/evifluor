# API Updates and Versions

The eviFluor Duo Fluorometer can be integrated through several software layers. Version information is useful when you validate a rollout, compare environments, or investigate a support issue.

The eviFluor Duo Fluorometer API software is open source and is maintained in the [eviFluor Duo Fluorometer GitHub repository](https://github.com/hseag/evifluor/).

## Practical Guidance

- Use a defined API and firmware version for each released integration.
- Check compatibility before updating the API or instrument firmware.

Re-check the API and firmware versions when updating the liquid handling software or integration. See [Release Notes](software-release-notes.md) for information on changes between API and firmware versions..
