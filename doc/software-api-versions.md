# API Updates and Versions

eviFluor Duo Fluorometer can be integrated through several software layers. Version information is useful when you validate a rollout, compare environments, or investigate a support issue.

The eviFluor Duo Fluorometer software is open source and is maintained in the [eviFluor Duo Fluorometer GitHub repository](https://github.com/hseag/evifluor/).

## Practical Guidance

- Treat the software version as part of the validated workflow, not as an isolated detail.
- Keep host software, device firmware, and integration assets aligned to the same approved release set.
- Re-check versions whenever a platform image, package, or robot setup is changed.

Use [Release Notes](software-release-notes.md) for the broader release view across firmware and interfaces.
