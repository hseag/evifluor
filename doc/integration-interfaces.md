# Available Interfaces

The eviFluor Duo Fluorometer offers multiple software interfaces for integration into different host systems and automation environments.

## High-Level Interface Choice

| Interface | Best fit | Reference |
| --- | --- | --- |
| Python high-level API | Guided workflows with minimal application code | [Python high-level API](python-high-level.md) |
| Python low-level API | Custom control over the measurement sequence | [Python low-level API](python-low-level.md) |
| Python REST API | Integration from external applications through HTTP | [Python REST API](python-rest.md) |
| C# API | .NET applications and Windows-centered software stacks | [C#](csharp.md) |
| C CLI | Scripting, service, and operational tooling | [C CLI](c-cli.md) |
