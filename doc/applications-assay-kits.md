# Assay Kits and Fit Types

The eviFluor Duo Fluorometer provides predefined assay kits for supported fluorescence assays. Different assay kits may require different algorithm fit types to calculate sample concentrations from the measured Relative Fluorescence Units (RFU).In eviFluor Duo the following predefined assay kits are currently available in the API:

- `QubitTM_1X_dsDNA_High_Sensitivity_HS`
- `QubitTM_1X_dsDNA_Broad_Range_BR`
