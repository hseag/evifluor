# Integration Paths

Choose the interface that best matches your automation environment.

| Situation | Recommended path |
| --- | --- |
| Python-based workflow or service | [Python Overview](python.md) |
| .NET-based application | [C# Overview](csharp.md) |
| Native or embedded integration | [C CLI](c-cli.md) |
| Language-independent service integration | [Python REST API](python-rest.md) |
| Workflow development without hardware | [Simulation and Testing](simulation.md) |

For each path, define command ownership, result handling, recovery behavior, and the required verification steps before deployment.

As a practical rule, choose the highest-level interface that still gives you the control your workflow requires. This keeps the integration easier to maintain and validate.
