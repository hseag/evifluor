# Opentrons OT-2

The Opentrons OT-2 integration kit provides a documented reference setup for running eviFluor Duo Fluorometer measurements on an OT-2 liquid handler.

## What You Need

To use the integration kit, you need:

- an Opentrons OT-2 liquid handler with access to the Opentrons App
- an Opentrons P20 Single-Channel GEN2 pipette
- an eviFluor Duo Fluorometer and a USB connection to the OT-2
- eviEtte Micro Cuvettes, reagents, and standard labware, such as 96-well microtiter plates
- a way to install the eviFluor Python package on the OT-2

Each protocol-specific user guide describes the required consumables and labware in detail.

## What We Provide

The integration kit includes a custom eviFluor Duo Fluorometer labware definition for the OT-2 deck. It also provides ready-to-use protocols for supported workflows, together with protocol-specific user guides for deck setup, parameters, and operation.

For the available protocols and their user guides, including installation, deck setup, run parameters, result handling, and operating instructions, see the [Opentrons OT-2 Liquid Handler Integration Guide](../../liquid-handler-ot2.md).
