# Applications

The eviFluor Duo Fluorometer supports automated fluorescence measurements as part of a liquid-handling workflow. Start here to understand the typical workflow and choose the appropriate assay kit and algorithm fit type.

- [Workflow](../applications-workflow.md) explains the sequence from sample preparation through measurement and result handling.
- [Assay Kits and Fit Types](../applications-assay-kits.md) describes the predefined assay kits and the available algorithm fit types used to convert measured Relative Fluorescence Units (RFU) into sample concentrations
- [Results and Data Handling](../applications-results-and-data-handling.md) for result handling and validation topics.
