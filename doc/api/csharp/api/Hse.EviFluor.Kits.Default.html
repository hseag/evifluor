Parameters

fitAlgorithm FitAlgorithm

Fit model used to convert the calibrated signal into a concentration.

k1 double

Primary scale factor applied to the fitted concentration.

k2 double

Offset added to the fitted concentration after scaling.

k3 double

Reserved third fit parameter for compatibility with existing kit definitions.

lookupTable LookupTable

Lookup table used when fitAlgorithm is LookupTable.

settlingTime double

Recommended settling time in seconds before taking a measurement.

stdHighTargetSignalFactor double?

Optional target factor for the high standard signal during first-sample auto-gain.

description string

Human-readable description used for diagnostics and serialization.
