Initializes a new run through the REST API.

Parameters:

  • nr_of_std_low – Number of low-standard replicates.

  • nr_of_std_high – Number of high-standard replicates.

  • concentration – Concentration assigned to the high standard.

  • no_air – If True, the run uses the sample-only workflow.

  • kit – Kit name or alias understood by the backend.

  • settling_time – Optional settling-time override in seconds.

  • k1 – Optional kit parameter override.

  • k2 – Optional kit parameter override.

  • k3 – Optional kit parameter override.

  • lookup_table – Optional lookup-table list or CSV/JSON filename.

Returns:

JSON response describing the initialized run.
