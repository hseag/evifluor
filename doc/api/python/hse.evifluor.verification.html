check(sample, hints=None, std_high_target_signal_factor=0.8)[source]¶

Dispatches verification based on the provided object type.

Parameters:

  • sample – Object to verify. Supported types include SingleMeasurement, AutoGainResult, FirstAirMeasurementResult, FirstSampleMeasurementResult, Measurement, and Results.

  • hints – Optional verification hints.

  • std_high_target_signal_factor – Target factor applied during standard-high verification.

Returns:

True if the object passes verification, otherwise False.
